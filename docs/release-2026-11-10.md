## 本地版本

- 31 个工具，68 个中英文可索引页面；旧版工具 URL 保留跳转。
- 整合已有视频分支中的旋转/翻转、裁剪、保留音调变速、静音/替换/混合音轨功能及输出验证。
- 补齐 16 张中英文分享图；构建会拒绝缺失或重复的工具定义，不再静默漏掉菜单中的工具。
- 修复音频转换的资源释放、取消状态及预览 URL 回收。
- 修复 Base64 错误输入、URL-safe 与 Data URI 同时启用时的编码，以及图片预览回收。
- 收紧时间输入，支持带空格的 PDF 页码范围，避免 PDF 异步销毁产生未处理错误。
- 文件选择器捕获异步读取/示例下载失败，防止重复处理，并允许重试。
- ffmpeg.wasm 0.12.10 的 ffprobe 在本机成功生成 JSON 时仍返回 -1；现在同时验证返回值和实际元数据，而非错误拒绝可读取的 AVI。
- 发布流程保留远端已有的 Chrome 沙箱配置及“检查通过才部署”要求，增加静态检查与完整本地处理验收。
